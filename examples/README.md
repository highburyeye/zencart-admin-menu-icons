# Optional upload-test asset

`mailbeez-bee.png` is an original coloured bee icon generated for MailBeez menu upload testing.
It is a transparent, 1254 × 1254 pixel PNG. Upload it without preparing or resizing it first.
The plugin converts it to a small PNG and contains it within the menu's fixed icon space.

This is an optional example asset, not an automatic default assignment.
It is not included in the install ZIP. Licence: GPL-2.0-only, as with this project.
